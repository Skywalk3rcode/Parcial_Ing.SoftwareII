Arquitectura de Módulos

Cada componente está diseñado con separación de responsabilidades y tipado estricto

🔍

1. Perfilado de Calidad

Cálculo de índice de calidad (0-100), detección de valores nulos, filas duplicadas, tipos incoherentes y detección de anomalías por IQR y Z-Score.

IQR Z-Score Gauge Plotly Detección de Tipos
🧹

2. Limpieza & Transformación

11 operaciones de limpieza con historial completo y capacidad de deshacer (Undo). Imputación inteligente, conversión de tipos, escalado y codificación One-Hot.

Historial con Deshacer One-Hot Encoding Escalado MinMax / Stand
📈

3. Exploración de Datos (EDA)

Estadísticas descriptivas completas, histogramas con KDE, boxplots, matriz de correlación interactiva (Pearson/Spearman) y análisis temporal.

Histogramas Correlación Boxplots Series de Tiempo
💰

4. Análisis Comercial y Ventas

Detección automática de columnas de ventas, ingresos, fechas y categorías. KPIs de ingresos, ticket promedio, Pareto 80/20 y tendencias mensuales.

Pareto 80/20 Ticket Promedio Tendencias Top Clientes/Prod
🤖

5. Machine Learning

Modelos de regresión (Linear, Ridge, RF, Gradient Boosting) y clasificación con métricas completas (R², RMSE, MAE, Accuracy, F1, Matriz de Confusión).

Regresión Clasificación Series Temporales Pipelines Scikit-Learn
📋

6. Historial & Reportes

Persistencia en base de datos SQLite de cada sesión y operación. Generador de reportes de auditoría exportables en CSV, Excel, HTML y JSON.

SQLite3 Exportación Excel Reportes HTML Auditoría

Ejecución en Entorno Local

Pasos sencillos para clonar y ejecutar en tu máquina

# 1. Clonar el repositorio
git clone https://github.com/Skywalk3rcode/Parcial_Ing.SoftwareII.git
cd Parcial_Ing.SoftwareII

# 2. Crear y activar entorno virtual
python -m venv venv
# En Windows:
.\venv\Scripts\activate
# En Linux/macOS:
source venv/bin/activate

# 3. Instalar dependencias
pip install -r requirements.txt

# 4. Ejecutar las pruebas unitarias
pytest tests/ -v

# 5. Iniciar la aplicación Streamlit
streamlit run app.py
